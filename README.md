# 🏫 Smart Campus Navigator

**Smart Campus Navigation & Facility Locator for JNTUA College of Engineering, Pulivendula.**

🌐 **Live Website:** [Open Smart Campus Navigator](https://jntua-pulivendula-smart-campus-navigator.ai.studio)

## 📌 About the Project

Smart Campus Navigator is a web-based platform designed to help students, parents, visitors, and event participants easily explore the college campus and locate important facilities.

## ✨ Key Features

- 🗺️ Interactive Campus Map
- 🔍 Search Campus Facilities
- 🏢 Department and Building Information
- 🚶 Walking Directions
- 📍 Facility Location Markers
- 🔐 Admin Dashboard

## 🎯 Project Objective

To make campus navigation easier by providing a centralized digital platform for discovering campus facilities and finding important locations.

## 🏛️ Institution

JNTUA College of Engineering (Autonomous), Pulivendula  
Andhra Pradesh, India

## 🚀 Project Status

Website deployed. Campus location data and navigation details require verification.
